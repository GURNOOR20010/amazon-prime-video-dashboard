# 🎬 Amazon Prime Video Dashboard

## 📊 Project Overview

This project presents an interactive **Amazon Prime Video Content Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides a comprehensive overview of the Prime Video catalog, helping analyze **titles, genres, ratings, directors, countries, release years, and content types**.

The goal of this project is to transform raw entertainment data into meaningful and interactive visual insights.

## 🎯 Objectives

- Analyze the overall Prime Video content catalog
- Compare **Movies vs TV Shows**
- Identify the most popular **genres**
- Analyze content based on **ratings**
- Explore the geographical distribution of shows
- Understand content growth across different **release years**
- Analyze the number of **directors and genres**

## 📈 Dashboard Features

### 🎭 Genre Analysis

Analyzes the number of titles across different genres and identifies the most popular categories.

### 📅 Release Year Analysis

Shows how the number of Prime Video titles has changed over the years.

### 🌍 Country Analysis

Interactive map showing the geographical distribution of Prime Video content.

### 🎬 Movies vs TV Shows

A donut chart compares the distribution of Movies and TV Shows.

### ⭐ Rating Analysis

Analyzes titles across different audience ratings such as:

- 13+
- 16+
- ALL
- 18+
- R
- PG-13
- 7+
- PG

### 📊 KPI Cards

Provides high-level metrics for quickly understanding the dataset.

## 💡 Key Insights

- **Movies represent the majority of the content** in the analyzed catalog.
- **Drama** is one of the most prominent genres.
- The dataset contains content spanning from **1920 to 2021**.
- Prime Video content is distributed across **multiple countries worldwide**.
- The catalog contains a large variety of **genres and directors**.
- Content ratings provide insight into different audience segments.
